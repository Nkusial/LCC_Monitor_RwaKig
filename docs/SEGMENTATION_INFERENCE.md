# U-Net Patch Inference

Phase 33 turns the trained weakly supervised U-Net checkpoint into local
prediction products.

## Inputs

```text
data/interim/models/unet_baseline.pt
data/interim/training_patches/training_patch_manifest.json
```

The checkpoint is generated by:

```powershell
python pipelines/15_train_unet_baseline.py --fit
```

## Command

```powershell
python pipelines/18_run_unet_inference.py
```

For a quick smoke test:

```powershell
python pipelines/18_run_unet_inference.py --split validation --limit 4
```

## Outputs

```text
data/interim/unet_inference/unet_inference_manifest.json
data/interim/unet_inference/*_unet_inference.npz
```

Each patch output stores:

```text
class_probabilities
dominant_class
max_probability
entropy
```

The dominant class excludes `background_or_unlabeled` because class `0` is the
training ignore label. Entropy is normalized from `0` to `1`, where higher
values mean the model is less certain among monitored land-cover classes.

## Interpretation

These outputs are not field-validated accuracy products. They are model-ready
probability and uncertainty products that can be mosaicked into rasters and
published in the WebGIS after visual and weak-label validation.

The first trained baseline can under-predict minority classes if the weak-label
patches are imbalanced. In the current local run, the inference manifest should
therefore be read together with `class_pixel_counts`, `mean_patch_max_probability`,
and `mean_patch_entropy` before any public accuracy claim.
